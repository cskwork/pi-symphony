# Symphony for Pi — v0.1 release report

## What shipped

Pi-native workflow foundation: one repository-local extension managing a single software-development task through **backlog → plan → build → review → verify → ready → (manual integration) → post-verify → done** with durable evidence.

- `SymphonyCore` command service — every mutation validated against the workflow graph *and* the target stage's output contract; append-only JSONL event ledger; atomic CAS task writes preserving human text.
- Independent review — fresh Pi SDK child session, bounded manifest (task contract, plan, diff, report, evidence), read-only tools. Review provenance is an engine invariant: an implementer-session report can never satisfy `review → verify`.
- Deterministic checks — fixed argv, mandatory timeouts, output caps, secret redaction, per-run evidence artifacts; missing artifacts downgrade recorded passes to `broken`.
- Crash recovery — execution lease with live-owner mutual exclusion, interrupted-attempt bookkeeping, torn-tail event tolerance, resume-without-budget vs retry-with-budget.
- Extension surface — `/sym` router (init/new/continue/status/doctor/recover/complete/checks/pause/resume/retry/cancel), 2-line widget, responsive overlay bounded to terminal height, `sym_*` tools, protected-path + destructive-command guard.

## Known limitations (v0.1)

- Single checkout, single active task, manual integration. No worktrees, scheduling, or delivery (v0.5/v0.6).
- The local HTML control plane ships in v0.2; the command/event seam is prepared.
- `roles.reviewer.model: inherit` uses the ambient default model; explicit model pinning lands with v0.3 role work.
- Windows: paths are normalized forward-slash internally; untested on Windows in this release.

## Security notes

The extension runs with **your user permissions — it is not a sandbox**. Protections are policy and confirmation: no `shell:true` anywhere; read-only git inspection allowlist; check environment allowlist; protected-path interception; destructive-command confirmation; secret redaction before persistence and transport.
