# Symphony for Pi — v1.0 release report (general availability)

## What this is

A production-ready Pi extension that takes software-development tasks through an evidence-gated lifecycle — Plan → Build → Review → Verify → Ready → (integration) → Done — with durable evidence, an independent fresh-context reviewer, deterministic checks, crash-safe recovery, customization, delegation, scheduling, controlled delivery, and a synchronized local web UI.

## GA release gates

- **Evidence owns status** — no required-check failure, timeout, unavailable, stale, or broken evidence can reach Ready or Done; provenance-gated review; digest-bound artifacts; file-vs-ledger reconciliation. (blockers/security tests)
- **Every mutation is explicit, validated, recoverable** — command service with output contracts, atomic CAS writes, append-only ledgers, idempotent RPC/dispatch/outbound operations, fenced leases, typed git mutations only. (all module tests)
- **Local-first, Pi-native, honest boundaries** — loopback-only web UI, default-off exports, redaction everywhere, documented non-sandbox limitations. (docs/security.md, docs/threat-model.md)
- **Fail-closed compatibility** — unsupported hosts refuse mutation; corrupted/mismatched state pauses rather than guesses. (hardening tests)
- **Documentation** — README, CHANGELOG, per-version reports (v0.1→v1.0), security model, threat model, troubleshooting.

## Final verification

Full suite, typecheck, real-pi smoke, and packaging metadata. See the verification block in the release commit.

## Supported matrix

- Pi 0.84.x, Node ≥ 22, Git ≥ 2.30, macOS/Linux (Windows: untested paths normalized).
- Schema v1 (migrated to v2 with preview/backup/rollback).

## Known limitations (honest scope)

- Not a sandbox: same-user processes can read/write `.symphony/`; protections bound the model and remote surfaces and make tampering detectable.
- No automatic production deployment; delivery is explicit and audited.
- Browser E2E via Playwright was deferred to post-GA (in-process protocol tests cover the contracts).
