# Symphony for Pi — v0.8 release report

## What shipped

Repository integrations, CI evidence, and observability (`src/integrations.ts`):

- **Adapter contracts** — capability descriptors (read/write surfaces, auth source, rate-limit semantics, error taxonomy) validated before registration; adapters return normalized snapshots and can never mutate task state directly.
- **Field sync** — remote changes to local-owned or concurrently-changed fields produce explicit conflicts, never silent overwrites; remote lifecycle labels map to *validated commands* only — unknown labels cannot jump stages.
- **Outbound operations** — typed, previewed, approval-linked, idempotent by key (lost responses replay the receipt, one remote effect total); push preflight verifies remote identity, branch policy, local head, and never authorizes force; divergence aborts.
- **CI evidence gating** — evidence is accepted only when its subject SHA equals the expected head and every required context is unambiguously present; local deterministic checks and remote CI remain distinct categories with retrieval timestamps.
- **Polling** — configured intervals with jitter, provider rate-limit/cooldown signals, window budgets.
- **Observability** — export is off by default and excludes prompts/source/diffs/task bodies/command output unless explicitly enabled; usage metrics distinguish provider-reported / estimated / unavailable, and unavailable is never zero; credential redaction across every integration surface (GitHub/GitLab/Slack tokens, bearer headers, key=value secrets).
- **Audit correlation** — local commands, approvals, remote operations, provider receipts, and workflow events correlate into reconstructable delivery timelines without transcripts.
