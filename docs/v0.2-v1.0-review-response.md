# v0.2–v1.0 review response — fixes applied

Source: `reviews/v0.2-v1.0-prd-compliance.md` (162 requirements audited) plus findings recovered from the adversarial review session (its report file was never written; findings were extracted from the session log and re-verified at HEAD before fixing).

## Blockers

| Finding | Fix |
|---|---|
| v1→v2 migration bricks the repo (loader rejected version 2) | Config loader accepts schema v2 (stages, invariants, skills catalog); `version: 3` still rejected with migration guidance; regression test asserts v2 round-trips |
| v0.5–v0.8 "library shelf" — modules unreachable by any user action | Wired into the product: `/sym worktree allocate|list|remove` (real typed git commands, preview, safe removal), `/sym queue` (scheduler projection with reason codes, capacity from `workspace.max_active_tasks` — now configurable 1–8), `/sym supervisor` (authority + reconciliation posture), `/sym delegate` and `/sym roles`/`sym handoffs` (v0.4), `/sym web` (v0.2). Custom v2 workflows now compile into the engine's transition/contract model (`core.activeGraph`), so `workflow.stages` actually changes gate behavior |

## Majors

- **configApply second write path** — the HTTP adapter now routes through `core.applyConfig` (validate → backup → atomic write → reload → durable `config.applied`); the adapter never writes config files.
- **Workflow customization inert** — `compileWorkflow` wired into the core; config `workflow.stages` loads, validates (conditions + graph invariants incl. "no evidence-free path to done"), and replaces the default graph.
- **pushPreflight ancestry stub** — replaced with a required `remoteIsAncestor` input (caller supplies a real `git merge-base --is-ancestor` result); the hardcoded `return false` is gone.
- **Reviewer tool override** (from the recovered adversarial session) — config now *rejects* mutation tools for `roles.reviewer` (explicit issue, not silent ignore); legitimate read-only tools are copied through; `SdkReviewerRunner` sanitizes independently (defense in depth).
- **Delegate handoff key collision** — idempotency keys include the role session id, so re-delegation no longer returns a stale handoff.

## Also fixed in this cycle (from the earlier self-review, same release)

EventBridge torn-tail event loss + cross-aggregate sequence collisions (global bridge sequences, idempotent-by-eventId tailing); SPA unescaped interpolations (stage/runState/status/id — now escaped); SupervisorAuthority concurrent-claim race (atomic mkdir + tombstone takeover); OutboundQueue concurrent duplicate transport effects (in-flight reservation); skill `entry` traversal (containment check).

## Known gaps — documented honestly

- The runtime state store is the JSONL ledger + rebuildable caches; no SQLite engine (V06-DB-* partially met by rebuildability semantics).
- No headless CLI process or GitHub adapter is shipped; `integrations.ts` provides the validated building blocks, wired surface TBD.
- Browser E2E via Playwright, SBOM/signing/soak, and a11y audits remain open; they are tracked as release-engineering work, not claimed as passed.
