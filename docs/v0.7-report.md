# Symphony for Pi — v0.7 release report

## What shipped

Detached runtime, resumability, and headless RPC (`src/runtime-supervisor.ts`):

- **Supervisor authority** — exactly one mutable authority per repository fingerprint via a pid-based lock: live foreign owners refuse, dead owners are reclaimed with a new epoch; reports from stale epochs or fencing tokens are rejected after takeover.
- **Reconciliation gate** — a supervisor enters Reconciling and may not dispatch until processes, leases, timers, workspaces, state store, and event offsets are all inspected.
- **Idempotent RPC log** — every mutating command requires command ID, idempotency key, actor, typed payload (and expected revision where applicable); identical retries return the original outcome, key reuse with a different payload fails; outcomes are durable snapshots for restart recovery.
- **Detachment contracts** — explicitly approved stage/role/tool/attempt/time budgets with pinned policy+task revisions; expiry, policy drift, or task drift stops the contract at the next safe boundary; every out-of-contract action is refused.
- **Durable event log** — monotonic sequences with watermark continuity (snapshot watermark + after() stream leaves no silent gap); retention truncation is explicit gap metadata, never silent absence.
- **Timers** — typed commands only (checks.run, task.retry, task.continue), deduplication keys make them idempotent across restarts and clock changes.
- **Version negotiation + diagnostics** — incompatible protocol majors refuse mutation with a concrete upgrade/downgrade path; diagnostic bundles redact secrets and include versions, health, projection offsets, process/lease summaries, reason codes, and bounded logs.
