# Symphony for Pi — v0.9 release report (release candidate)

## What shipped

Hardening (`src/hardening.ts` + docs):

- **Compatibility matrix** — startup validates Pi/Node/Git/OS/schema before enabling mutation; unsupported hosts fail closed with actionable remediation (read-only inspection at best, refuse for newer schemas). Zero speculative mutation.
- **Threat model with traceability** — `docs/threat-model.md` + `auditThreatModel()`: every critical threat must name a control and traced test IDs; the audit is test-enforced.
- **Adversarial path corpus** — traversal, suffix traversal, redundant separators, dot segments, case folding, escape-sequence injection; `isContained()` resolves segments and rejects null/escape bytes.
- **Migration journal** — start/complete/fail steps with exact resume-after-kill semantics.
- **Performance budgets** — named budgets for parse, ledger append, projection, gate evaluation, snapshot; pagination bounds large sets (10k items → 100-item pages) instead of memory exhaustion.
- **Resource limits** — single source of truth for body/artifact/stream/log/diff caps.
