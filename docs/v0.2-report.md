# Symphony for Pi — v0.2 release report

## What shipped

Synchronized local HTML control plane over the same command/event seam as the TUI:

- **Protocol (frozen first):** `src/web/protocol.ts` — view models, command envelope, stable error codes, SSE replay rules, loopback/origin/credential validators. 16 contract tests without any browser code.
- **Server:** `src/web/server.ts` — loopback-only bind, per-route auth (host/origin/bearer token/content-type/size caps), `/api/v1/{health,snapshot,events,config,config/validate,config/apply,commands,artifacts/*}`, SSE with Last-Event-ID replay and `snapshot_required` fallback, command audit log, config draft→validate→diff→apply with atomic write + backup + `config.applied` event.
- **SPA:** `src/web/spa/` — zero-dependency single-page app (Overview / Tasks / Active Run / Review / Verification / Configuration / Diagnostics), explicit connection states (Live/Reconnecting/Snapshot/Disconnected), revision-conflict prompts, keyboard navigation (1–7), responsive to 390px.
- **Extension:** `/sym web [start|open|status|stop]` lifecycle; server stops with the session.

## Verification

- 194 tests (18 files) — includes 16 protocol-contract and 11 live-server tests (auth matrix, SSE replay, config lifecycle, traversal rejection, idempotent stop).
- Smoke harness: extension loads in real pi, all commands exit 0.
- Not covered here: real-browser E2E (Playwright) — deferred to the v0.9 hardening pass per roadmap; in-process tests cover the same contracts.
