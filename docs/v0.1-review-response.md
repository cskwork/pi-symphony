# v0.1 review response — fixes applied

Both v0.1 reviews (`reviews/v0.1-prd-compliance.md`, `reviews/v0.1-adversarial.md`) were acted on in full. Every blocker and every major from both reports is fixed with a regression test; minors are fixed unless noted below.

## Blockers

| Finding | Fix | Test |
|---|---|---|
| blocked→ready reachable with zero evidence | `contractFor()` gives every `blocked→X` edge the target stage's entry contract | `blockers.test.ts` (3 cases) |
| self-submitted review satisfies review→verify | `StageReport.origin` provenance; `requiresReviewProvenance` on review→verify edges (also blocked→verify); model-submitted reviews can never certify | `blockers.test.ts` (3 cases incl. replay) |
| E1 trust boundary (tasks/evidence/config writable, bash unscanned) | default protected paths now cover `.symphony/**`, nested/case-variant `**/.env*`, `.envrc`; tasks/evidence/runtime/git are **always-block** for model writes; bash redirect/tee/dd targets classified through the same guard; realpath resolution for symlink aliases; outside-cwd escapes blocked | `security.test.ts` guard cases |
| E2 replay trusts tampered artifacts/ledger | sha256 artifact digest recorded in `check.completed`, verified on rehydrate → `broken`; file-vs-ledger stage reconciliation on load (forged stage clamped, integrity report) | `security.test.ts` tamper cases |
| E3 stale evidence via direct transition | `transition()` refuses check-gated edges (→ready/→done) synchronously; only `advanceToReady`/`completeTask` run them with a live revision | `security.test.ts` |

## Majors

- Reviewer isolation + role config: session plan (read-only tools, noExtensions/noSkills/noContextFiles, cwd=repoRoot, thinking, max_turns with fail-closed turn cap) — `reviewer-contract.test.ts`.
- Missing-artifact → `broken` downgrade before every gate — `blockers.test.ts`.
- Plan-discovered risks merged into the contract; approval required (policy not evadable) — `blockers.test.ts`.
- Plan-approval invalidated by a newer plan (revision-bound, cache bug fixed) — `security.test.ts` E5.
- Zero-check config hole: empty or no-required check sets rejected; `pinnedConfigHash` drift blocks Ready/Done — `security.test.ts`.
- Lease mutual exclusion (live foreign owner refuses); recover() respects a live foreign owner; unreadable leases reclaimable — `lease.ts` + tests.
- Resume (same attempt, no budget) vs Retry (new attempt) — `core.resumeAttempt` + tests.
- HEAD integration wedge: symbolic refs rev-parsed to full shas; repair path when the checkout moved but is still on target — `security.test.ts` O1.
- TUI gate: overlay height-bounded at any terminal size with scrolling list + detail budget; snapshots at 80×24/110×30/160×45; actions act on the *selected* task — `overlay-snapshots.test.ts`.
- Packaging: `scripts/smoke-load.mjs` (5 checks green), `files` allowlist, docs (report + security model), npm round-trip of config serialization.
- R7 task-id traversal: strict id format at every core entry point + path containment — `security.test.ts`.
- K3 allocator race: O_EXCL claim files; empty claims treated as new.
- K2/K4 attempt ids namespaced per task; system aggregates get a separate event stream.
- S3 git allowlist: per-subcommand **option allowlist** (deny-by-default), `config --get/--get-regexp` only, `--exec=`/`--output=` rejected structurally.
- S4 redaction: ENV-style names (`AWS_SECRET_ACCESS_KEY=…`), Bearer/JWT; redact-before-slice.
- S5 executor: detached process groups + group kill on timeout (grandchildren reaped), bounded output buffering with drop accounting.
- S6 reviewer hardening: untrusted diff fenced (`<diff>` markers), task file readable only for the reviewed id.
- D1/D2 parser: CRLF tolerance, duplicate-marker collapse (first wins), orphan markers treated as human text.
- C1 durability: fsync on task writes before atomic rename.
- O2 yamlScalar: YAML-unsafe scalars (booleans/numbers like `true`) quoted; round-trip test.
- O3 widget AC progress derives from implementation report statuses; non-Git checkouts complete with evidence marked unavailable.
